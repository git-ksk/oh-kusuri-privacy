# 隱私權政策

**最後更新：2026 年 9 月 18 日**

本隱私權政策說明開發者如何在 Oh!我的藥（以下稱「本 App」）處理資訊。

## 1. 藥品與服藥資料

本 App 不需要註冊或建立帳號。你輸入的藥品、保健品、服藥排程與紀錄、庫存資訊及備註，原則上都儲存在你的裝置上。本 App 不會持續將這些個人資料同步到我們的雲端。藥品名稱、自由輸入備註、症狀備註及原始搜尋詞不會作為 Firebase Analytics 或 Crashlytics 的自訂欄位傳送。

## 2. 更換裝置

只有當你在設定中明確開始更換裝置時，本 App 才會在裝置端加密藥品與服藥資料，並將加密資料傳送到暫時性的轉移服務。

- 轉移內容使用由復原碼在本機衍生的金鑰加密。一般伺服器處理不會收到明文的藥品名稱、服藥紀錄、備註或症狀。
- 加密轉移資料最多可使用 **72 小時**。成功復原或你停用轉移後，我們會在可行的情況下立即使其失效並刪除。若暫時發生通訊或清理失敗，72 小時期限仍是最終的保存上限。
- 新裝置解密需要復原碼。我們不保存復原碼，也無法找回或重新發行遺失的復原碼。
- 為防止濫用，我們使用 Firebase App Check 與請求頻率限制。網路資訊可能會為此目的被處理；營運中繼資料保存的是單向衍生識別值，而不是原始 IP 位址。
- 更換裝置是明確啟動的暫時轉移，不是帳號型備份或持續雲端同步。

## 3. 藥品搜尋與建議

在支援的國家或地區，搜尋詞可能會傳送到公共或第三方藥品資訊服務，或由我們營運的搜尋代理，以取得建議。本 App 不會在這些請求中加入服藥紀錄、庫存、備註或症狀。

## 4. 使用分析

本 App 使用 **Google Firebase Analytics** 改善品質。可能包含 App 版本、語言、功能操作、分組後的數量及技術資訊。自訂事件不會包含藥品名稱、備註、症狀、原始搜尋詞、復原碼、轉移用秘密資訊或轉移資料本體。Analytics 不用於廣告或使用者追蹤。

## 5. 當機與錯誤診斷

本 App 使用 **Google Firebase Crashlytics**。App 額外傳送的非致命診斷僅限預先定義的操作名稱、階段、錯誤分類與數字代碼，不包含醫療內容或轉移秘密資訊，也不設定自訂 Crashlytics 使用者 ID。你可在設定中停用收集；變更可能要到下次啟動後才完全生效。

## 6. 廣告與追蹤

本 App 目前不顯示廣告、不使用 Google AdMob，也不透過 ATT 進行廣告追蹤。

## 7. 第三方服務與雲端基礎設施

本 App 使用 Firebase 與 Google Cloud。加密的裝置轉移資料及最少必要的營運中繼資料，會暫時在我們管理的 Google Cloud 基礎設施上處理與保存。

- [Google 隱私權政策](https://policies.google.com/privacy)
- [Firebase 隱私權與安全性](https://firebase.google.com/support/privacy)
- [Google Cloud Privacy Notice](https://cloud.google.com/terms/cloud-privacy-notice)

## 8. 政策變更

當功能或使用的服務有所變更時，我們可能更新本政策。
